# 女娲AI自我进化系统使用指南

## 🎯 系统概述

女娲AI的自我进化系统基于**强化学习（Reinforcement Learning）**，能够：
- 📊 自动分析对话质量
- 🧠 学习最优人格调整策略
- 🔄 持续优化交互体验
- 🎭 动态调整13个人格参数

## 🏗️ 架构图

```
用户交互 → 记录交互 → 计算奖励 → 经验回放 → Q网络训练 → 策略应用 → 人格更新
   ↓          ↓          ↓          ↓          ↓          ↓          ↓
KernelDI → Interaction → Reward → ReplayBuffer → QNetwork → Evolution → StateManager
```

## 🚀 快速开始

### 1. 自动模式（推荐）

```python
from nuwa_core.kernel_di import KernelDI
from nuwa_core.config_manager import NuwaConfig

# 创建内核（自动包含自我进化）
kernel = KernelDI(config=NuwaConfig())

# 正常对话，系统会自动记录和进化
result = await kernel.process_input("你好，今天心情不错")

# 查看进化状态
status = kernel.get_status()
print(f"进化次数: {status['self_evolution_stats']['evolution_count']}")
```

### 2. 手动模式

```python
from nuwa_core.self_evolution_rl import SelfEvolutionRL, Interaction

# 创建进化器
evolution = SelfEvolutionRL(state_manager, memory_cortex, llm_client)

# 手动记录交互
interaction = Interaction(
    user_input="你真棒",
    ai_response="谢谢你的夸奖！",
    user_satisfaction=0.9,
    quality_score=0.85,
    emotional_stability=0.9
)

# 执行进化
result = await evolution.evolve([interaction])
```

## 🔧 进化流程

### 1. 交互记录
```python
# 每次对话后自动记录
interaction = Interaction(
    user_input=user_input,
    ai_response=reply,
    user_satisfaction=0.8,  # 需要评估
    quality_score=0.75,     # 需要评估
    emotional_stability=0.9 # 需要评估
)
```

### 2. 奖励计算
```python
reward = evolution.calculate_reward(interaction)
# 0.8 + 0.75 + 0.9 / 3 = 0.817
```

### 3. 经验存储
```python
# 自动添加到经验缓冲区
replay_buffer.add(interaction, reward)
```

### 4. 触发训练
```python
# 当经验 >= 阈值时自动训练
if len(replay_buffer) >= experience_threshold:
    await evolution.train_evolution_policy()
```

### 5. 策略应用
```python
# 基于当前状态选择最优动作
best_action = evolution.select_action(current_state)
# 应用动作到状态管理器
evolution.apply_action(best_action)
```

## 🐛 常见问题

### Q: 进化不触发？
**A:** 检查交互历史是否达到阈值，或进化冷却时间是否结束

### Q: 奖励总是很低？
**A:** 可能是评估函数需要优化，检查用户满意度、对话质量、情绪稳定性的评估逻辑

### Q: 训练很慢？
**A:** 降低批次大小或减少状态维度，或使用NumPy模式

### Q: 如何重置进化？
**A:** 删除经验缓冲区文件，或调用`evolution.replay_buffer.clear()`

## 📈 最佳实践

1. **循序渐进**: 从低阈值开始测试，逐步提高
2. **定期监控**: 查看进化状态和训练损失
3. **平衡探索**: 保持适当的epsilon值（0.1-0.2）
4. **多样化数据**: 确保交互历史足够多样
5. **及时评估**: 准确评估对话质量
