# API配置管理使用说明

## 功能概述

新的前端API配置管理功能支持：
- ✅ 保存多个API配置
- ✅ 快速切换不同后端服务
- ✅ 管理API密钥和地址
- ✅ 本地存储自动保存

## 使用方法

### 1. 打开设置菜单
1. 在主界面右上角点击 ⚙️ 设置按钮
2. 在设置菜单中找到 **🔌 API配置管理** 部分

### 2. 添加新配置
1. 点击 **"添加"** 按钮
2. 填写配置信息：
   - **配置名称**: 如 "本地LM Studio"、"云端API"
   - **WebSocket地址**: 如 `ws://127.0.0.1:8766`
   - **LLM API地址** (可选): 如 `http://127.0.0.1:1234/v1`
   - **API密钥**: 如 `lm-studio`
   - **模型名称**: 如 `local-model`
   - **描述**: 可选的配置说明
3. 点击 **"保存配置"**

### 3. 编辑现有配置
1. 在下拉菜单中选择要编辑的配置
2. 点击 **"编辑"** 按钮
3. 修改需要的字段
4. 点击 **"保存配置"**

### 4. 删除配置
1. 在下拉菜单中选择要删除的配置
2. 点击 **"删除"** 按钮
3. 确认删除操作

### 5. 应用配置
1. 在下拉菜单中选择要使用的配置
2. 点击 **"应用当前API配置"** 按钮（绿色按钮）
3. 系统会自动：
   - 更新WebSocket连接地址
   - 重新连接服务器
   - 显示成功提示

## 故障排除

### 问题1: 无法连接到服务器
**解决方案**:
1. 确认后端服务已启动
2. 检查WebSocket地址是否正确
3. 查看浏览器控制台错误信息

### 问题2: 配置无法保存
**解决方案**:
1. 检查浏览器是否启用了localStorage
2. 清理浏览器缓存后重试
3. 确认填写了必填字段（配置名称、WebSocket地址）

### 问题3: 切换配置后没有效果
**解决方案**:
1. 确保点击了"应用当前API配置"按钮
2. 检查原WebSocket连接是否已关闭
3. 刷新页面后重试

## 技术细节

### 数据存储
- 配置保存在浏览器的 `localStorage` 中
- 键名: `nuwaSettings`
- 格式: JSON字符串

### 配置结构
```javascript
{
  apiConfigs: [
    {
      name: "配置名称",
      wsUrl: "ws://地址:端口",
      llmUrl: "http://地址:端口/v1",
      apiKey: "密钥",
      model: "模型名称",
      description: "描述"
    }
  ],
  currentApiConfig: 0  // 当前使用的配置索引
}
```

### 兼容性
- 支持从旧格式 `nuwa_settings` 自动迁移
- 向后兼容现有设置

## 注意事项

1. **必填字段**: 配置名称和WebSocket地址为必填项
2. **端口检查**: 确保端口未被其他程序占用
3. **跨域问题**: 如果使用远程服务器，确保后端支持CORS
4. **密钥安全**: API密钥仅保存在本地浏览器中
5. **连接状态**: 应用配置后会自动重连，可能需要几秒钟
