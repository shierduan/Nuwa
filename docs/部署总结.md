## 🔧 配置说明

### WebSocket配置
- 默认地址: `ws://127.0.0.1:8766`
- 在 `main.js` 的 `settings.backendUrl` 中修改

### 模型配置
- 默认模型: `openSource`
- 模型路径: `models/openSource/openSource.model3.json`
- 在设置菜单中可切换模型

### Electron配置
- 窗口大小: 800x600（可配置）
- 窗口置顶: 默认开启
- 鼠标穿透: 锁定模式下启用

## ⚠️ 注意事项

### 前提条件
1. **Python 3.8+** - 运行后端服务
2. **Node.js 14+** - 运行Electron（可选）
3. **本地LLM服务** - 默认在 `http://127.0.0.1:1234/v1`
4. **Live2D模型** - 需要 `models/openSource/` 目录

### 端口占用
- WebSocket: 8766
- Flask后端: 5000（可选）

### 防火墙设置
- 确保本地回环地址（127.0.0.1）允许WebSocket连接

## 📞 故障排除

### 问题1: 启动管理器无法启动程序
**原因**: 浏览器安全限制，无法直接启动外部程序

**解决**: 
- 使用启动管理器查看命令
- 手动在终端运行命令
- 或使用 `launch_server.py` 提供API支持

### 问题2: WebSocket连接失败
**原因**: 服务器未启动或端口被占用

**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :8766

# 启动服务器
python server_async.py
```

### 问题3: 模型不显示
**原因**: 模型文件缺失或路径错误

**解决**:
- 检查 `models/openSource/` 目录
- 确认存在 `openSource.model3.json`
- 查看浏览器控制台错误
