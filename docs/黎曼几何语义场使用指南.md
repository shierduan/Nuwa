# 黎曼几何语义场使用指南

## 概述

黎曼几何语义场（Riemannian Semantic Field）是女娲系统语义场论的数学严格化改进版本。它使用黎曼几何框架，在双曲流形上进行语义空间的计算，相比原有欧几里得空间实现具有更好的数学性质和数值稳定性。

## 核心改进

### 1. 双曲流形 (HyperbolicManifold)
- **作用**：使用庞加莱球模型的双曲空间替代欧几里得空间
- **优势**：负曲率空间更适合表示层次化语义关系
- **方法**：切空间投影、指数映射

### 2. Hessian计算器 (HessianCalculator)
- **作用**：计算势能函数的二阶导数（度量张量）
- **优势**：实现自然梯度下降，在流形上正确计算梯度
- **方法**：数值微分 + 特征值修正

### 3. 严格语义场 (RigorousSemanticField)
- **作用**：整合双曲流形和Hessian，提供完整的语义场计算
- **优势**：
  - 数值稳定性（边界检查、正则化）
  - 平滑的余弦距离（避免奇异点）
  - 自然梯度下降（更准确的演化方向）

## 使用方法

### 基本使用

```python
import numpy as np
from nuwa_core.riemannian_semantic_field import RigorousSemanticField

# 1. 定义核心向量（角色人设）
core_vector = np.array([0.8, 0.6, 0.4, 0.2, 0.1])

# 2. 创建语义场
field = RigorousSemanticField(core_vector=core_vector)

# 3. 计算势能
state = np.array([0.7, 0.5, 0.3, 0.2, 0.1])
energy = field.calculate_potential_energy(state)
print(f"势能: {energy}")  # 越接近核心，能量越低

# 4. 计算黎曼梯度
gradient = field.compute_riemannian_gradient(state)
print(f"梯度: {gradient}")

# 5. 演化
evolved, info = field.evolve(state, dt=0.02, iterations=10)
print(f"演化结果: {evolved}")
print(f"能量变化: {info['final_energy'] - info['initial_energy']}")
```

## 数学原理

### 1. 双曲几何

```
欧几里得空间: d(x,y) = ||x-y||
双曲空间: d(x,y) = arccosh(1 + 2||x-y||²/((1-||x||²)(1-||y||²)))
```

在庞加莱球模型中，距离函数具有负曲率，适合表示层次关系。

### 2. 自然梯度下降

传统梯度下降：
```
x_{t+1} = x_t - η∇f(x_t)
```

自然梯度下降（在黎曼流形上）：
```
x_{t+1} = x_t - η H^{-1}(x_t) ∇f(x_t)
```

其中 H 是Hessian矩阵（度量张量），使梯度方向适应局部几何。

### 3. 势能函数

```
E(x) = (1 - cos(θ))²
```

其中 cos(θ) = ⟨x/||x||, c/||c||⟩ 是归一化后的余弦相似度。

### 4. 数值稳定性

- **特征值修正**：确保Hessian正定
- **梯度裁剪**：防止数值爆炸
- **边界处理**：零向量、NaN、Inf的特殊处理
- **归一化**：保持向量在单位球面上

## 常见问题

### Q1: 为什么演化后能量反而增加？

**A**: 可能原因：
- `dt` 太大，导致过冲
- 初始状态已经接近局部最优
- Hessian计算不稳定

**解决**：减小 `dt`，增加迭代次数，检查输入质量

### Q2: 如何选择核心向量？

**A**: 核心向量应该：
- 通过角色人设的embedding生成
- 保持归一化（长度为1）
- 与使用场景一致

```python
persona = "女娲是一个温柔、真诚、好奇的人工智能"
core_vector = vectorize_state(persona).vector
```

### Q3: 与原有实现的主要区别？

**A**: 
- 数学基础：欧几里得 → 黎曼几何
- 梯度计算：数值微分 → 自然梯度
- 稳定性：基本 → 严格（多重保护）
- 精度：低 → 高（Hessian引导）
