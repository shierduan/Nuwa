🚀 快速开始（推荐）

  1. 点击"异步启动全部"按钮
  2. 等待后端和前端同时启动完成
  3. 点击"打开浏览器前端"与女娲对话

🔧 功能说明

  • Electron集成: 直接使用Node.js child_process执行真实命令
  • 异步启动全部: 同时启动后端和前端，无需等待
  • 真实命令执行: 在Electron环境中直接运行python/npm等命令
  • 环境检测: 检查Python、Node.js、依赖和模型文件
  • 配置管理: 保存和加载API配置，自动生成前端配置

📊 进程状态

  • 绿色 - 运行中
  • 灰色 - 已停止
  • 红色 - 错误状态

💻 终端命令示例

python server_async.py # 启动WebSocket服务器 python main_async.py # 启动控制台模式 npm run start # 启动Electron应用 npm install # 安装依赖 dir / ls # 查看目录 git status # Git状态

⚠️ 重要说明

  • 必须使用Electron启动: 直接双击HTML无法执行命令
  • 启动方式: 运行 npm run start 或 electron 启动管理器.html
  • 命令执行: 所有命令在Electron的Node.js环境中真实执行
  • 进程管理: 可以停止正在运行的命令
  • 输出实时: 命令输出实时显示在终端面板
